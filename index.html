공문, 붙여넣으면
요약이 끝납니다

복사한 공문 본문을 붙여넣으면 Gemini가 핵심·조치사항·기한·신청 링크까지 정리해 클립보드에 담아 드립니다. 페이지 접근·결재·전송은 하지 않습니다.

소스 & 다운로드 설치 방법 보기

Features

필요한 것만, 깔끔하게

붙여넣기 한 번

아이콘을 열면 클립보드 내용이 입력창에 자동으로 첨부됩니다. 복사 → 열기 → 요약, 세 동작이면 끝.

두 가지 요약 형식

핵심·조치사항·기한·담당을 정리하는 상세 요약과, 동료에게 바로 전달할 쿨메신저 안내문 형식을 고를 수 있습니다.

신청 링크 보존

접속해 신청·등록해야 하는 URL과 하이퍼링크를 원문 그대로 담아, 요약 과정에서 빠뜨리지 않습니다.

최소 권한

storage·clipboardRead와 Gemini 호출 권한만 사용합니다. 페이지를 읽거나 바꾸지 않습니다.

본인 Gemini 키

발급받은 API 키를 넣어 직접 호출합니다. 기본 모델은 항상 최신 플래시로 연결됩니다.

결재·전송 없음

상신·결재·발송을 자동화하지 않습니다. 오직 붙여넣은 텍스트를 요약하는 일만 합니다.

Install

3분이면 설치 완료

1

Gemini API 키 발급

aistudio.google.com/apikey 에서 Create API key → 생성된 키(AIza…) 복사

2

코드 내려받기

GitHub에서 저장소를 Code → Download ZIP 으로 받아 압축을 풀거나 git clone 합니다.

3

크롬에 로드

주소창에 chrome://extensions → 우측 상단 개발자 모드 ON → 압축해제된 확장 프로그램을 로드 → 압축 푼 폴더 선택

4

키 저장 후 사용

툴바 아이콘 클릭 → ⚙에서 API 키를 저장하면 준비 완료. 공문 본문을 복사해 붙여넣고 요약하기를 누르세요.

사용 전 확인하세요

  • 붙여넣은 텍스트는 요약을 위해 외부(Gemini API)로 전송됩니다. 개인정보·비공개(비밀) 문서에는 사용하지 마세요.
  • 외부 API 전송이 소속 기관 보안정책에 저촉되지 않는지 정보보안 담당자에게 확인하시기 바랍니다.
  • 이 확장은 요약만 수행하며 결재·상신·전송을 자동화하지 않습니다.
