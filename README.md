# 공문 요약 도우미 (크롬 확장)

**복사한 본문을 붙여넣으면** Gemini로 요약해 클립보드에 복사합니다.
페이지 접근·결재·전송 등 시스템 조작은 일절 하지 않으며, **붙여넣은 텍스트만** 외부(Gemini API)로 전송합니다.

---

## 1. 필수 사전 설정

**Gemini API 키 발급**
1. https://aistudio.google.com/apikey 접속 → `Create API key`
2. 생성된 키(`AIza...`) 복사

---

## 2. 설치 (개발자 모드)

1. 이 폴더의 압축을 풀어 원하는 위치에 둡니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** ON
4. **압축해제된 확장 프로그램을 로드** 클릭 → 이 폴더 선택
5. 툴바 아이콘 핀 고정 권장. 기존 버전을 쓰던 경우 **새로고침(↻)** 하세요.

---

## 3. 사용법

1. 요약할 공문 **본문을 드래그해 복사(Ctrl+C)**
2. 확장 아이콘 클릭 → 클립보드 내용이 입력창에 **자동 첨부**됨
   (자동이 안 되면 입력창에 Ctrl+V, 또는 "클립보드 붙여넣기" 버튼)
3. 요약 형식 선택 후 **요약하기**
   - 상세 요약: 핵심·조치사항·기한·담당 + 쿨메신저 전달용 1~2줄
   - 짧은 버전: 쿨메신저 전달용 1~2줄만
4. **복사** → 쿨메신저에 붙여넣기

> 처음 실행 시 ⚙에서 API 키·모델을 저장하세요.

---

## 4. 설정값

| 항목 | 기본값 | 비고 |
|---|---|---|
| 모델 | `gemini-flash-latest` | 항상 최신 플래시로 자동 연결. 명시하려면 `gemini-3.5-flash`, 저렴하게는 `gemini-3.1-flash-lite` |
| 전송 상한 | 12,000자 | `popup.js`의 `MAX_CHARS` |
| temperature | 0.2 | 사실 위주 요약용 |

권한: `storage`, `clipboardRead`, 그리고 Gemini API 호출용 host 권한만 사용합니다.
(페이지를 읽거나 변경하는 권한은 없습니다.)

---

## 5. 보안·규정 유의

- 이 확장은 **요약만** 수행하며 결재·상신·전송을 자동화하지 않습니다.
- 붙여넣은 텍스트가 외부 API로 전송되므로 **개인정보·비공개(비밀) 문서에는 사용하지 마세요.**
- 외부 API 전송이 소속 기관 보안정책에 저촉되지 않는지 정보보안 담당자에게 확인하시기 바랍니다.
